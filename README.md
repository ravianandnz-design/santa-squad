# Santa Squad

Shared family Christmas wishlists with three access roles:

- **Organiser link:** create children and their private edit links.
- **Child edit link:** add or remove only that child's wishes.
- **Family gift link:** see all wishes and reserve one. Reservations are never shown to children.

## Future-ready additions

The data model already supports multiple families, revocable links and more children. Natural next steps: item photos, budgets, age-appropriate lists, a “bought/wrapped” status visible only to adults, and annual archive/copy-forward.
